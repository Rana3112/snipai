  1. PROJECT OVERVIEW                                                           
  SnipAI is a Windows AI screen-snipping agent. User runs a global hotkey,      
  draws a crop on the screen, the snip image + optional typed question get sent 
  to a hosted backend, and the streamed AI answer appears in a floating chat

  --windowed).                                                                  
  Why a backend? All major vision-capable AI providers (OpenAI, Anthropic,      
  Google, Groq, etc.) reject CORS / direct browser calls from desktop apps for  
  image uploads. A thin FastAPI proxy in the middle forwards the request using  
  the user's BYOK (Bring Your Own Key) and streams SSE back. The backend never  
  stores the user's API key — it only uses it for the current request.
